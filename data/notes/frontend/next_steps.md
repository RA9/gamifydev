# Next Steps

Take a moment — you've earned it. You started not knowing how a web page works, and now you can structure one with HTML, style it with CSS, make it interactive with JavaScript, track it with Git, and ship a portfolio. That's a genuine foundation.

So… where to now? Let's map it out.

## You are here

![A learning roadmap: frameworks, backend, real projects, job-ready](/images/lessons/roadmap.svg)

The road ahead isn't a single straight line, but most front-end journeys pass through the same milestones. You don't need all of them at once — pick what excites you next.

:::analogy
Learning to code is less like climbing a ladder and more like levelling up in a game. You don't unlock everything at once — you take on the next quest that interests you, get a bit stronger, and the one after that becomes reachable.
:::

## Solidify the fundamentals first

Before chasing shiny tools, make the basics *automatic*. The strongest developers have rock-solid fundamentals.

- Rebuild a layout you like from scratch, no tutorial.
- Practise JavaScript with small challenges (arrays, loops, functions).
- Get comfortable reading documentation, like [MDN Web Docs](https://developer.mozilla.org).

:::tip
The fastest way to improve is to **build things slightly harder than what you can comfortably do**, and finish them. Tutorials teach; finishing projects transforms.
:::

## Where to go next

A few popular directions, roughly in order:

1. **A framework** — once plain JavaScript feels comfortable, learn **React** (or Vue/Svelte). Frameworks make big, interactive apps manageable.
2. **Backend & APIs** — learn how servers and databases work (Node.js, Python). This lets you store data and build full applications.
3. **Tooling & deployment** — package managers, the command line, and deploying real projects.
4. **Go deeper on craft** — accessibility, performance, and clean, testable code. This is what separates good developers from great ones.

## Habits that compound

- **Build in public** — share your projects and progress. It builds a network and keeps you accountable.
- **Read other people's code** — open source on GitHub is a free masterclass.
- **Be consistent** — 30 focused minutes a day beats an occasional all-nighter.

:::key
You have the fundamentals. Now **build, finish, and share** projects slightly beyond your comfort zone, then branch into a framework and the backend when you're ready. Consistency beats intensity.
:::

## Talk about it

Set your direction out loud:

> "What will I build next, and which one new skill — a framework, the backend, or deeper craft — will I explore after that?"

Naming it makes it real. You've got the foundation; the rest is momentum.

## Keep going

There's no finish line in this field — and that's the fun of it. Every developer you admire was once exactly where you are now. Keep building. 🚀
