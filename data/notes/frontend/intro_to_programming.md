# Intro to Programming

Before you write a single line of HTML, it helps to understand what *programming* actually is. At its heart, programming is giving a computer a clear, step-by-step set of instructions to follow.

## What is a program?

A program is just a list of instructions. Computers are fast but literal — they do exactly what you say, in the exact order you say it. Learning to code is really learning to think clearly and break big problems into small, precise steps.

## Core building blocks

Almost every programming language shares the same core ideas:

- **Values & data types** — numbers, text (called *strings*), and true/false values (*booleans*).
- **Variables** — named boxes that store a value so you can reuse it later.
- **Conditions** — *if this is true, do that* — letting programs make decisions.
- **Loops** — repeating an action many times without copying code.
- **Functions** — reusable, named blocks of instructions you can run on demand.

## A tiny example

Here is the idea of a variable and a condition in plain language:

- Store the number `18` in a variable called `age`.
- **If** `age` is 18 or more, show "You can vote".
- **Otherwise**, show "Not yet".

You will write this exact logic in real code soon, in the JavaScript lessons.

## How code runs in the browser

The web has three core languages, and each has a job:

- **HTML** — the *structure* and content of a page.
- **CSS** — the *styling*: colors, layout, spacing.
- **JavaScript** — the *behavior*: making pages interactive.

You will learn all three on this path. Next up: **HTML Basics**, where you build the skeleton of a web page.

## Key takeaways

- Programming is breaking problems into small, precise steps.
- Variables, conditions, loops, and functions appear in nearly every language.
- On the web, HTML structures, CSS styles, and JavaScript adds behavior.
