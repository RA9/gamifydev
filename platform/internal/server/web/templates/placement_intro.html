Before you begin

This is a supervised test.

Your browser watches for three things while the paper is open. The first time it sees one you get a warning. The second time, the test closes itself and is marked as failed for cheating.

{{ icon "file" }}

Don't copy the questions

Copy, cut and right-click are disabled for the duration of the paper.

{{ icon "search" }}

Don't capture the screen

Printing and saving are blocked, and capture shortcuts are recorded.

{{ icon "arrowright" }}

Don't leave the tab

Switching tabs or windows counts, so close everything else first.

{{ icon "shield" }} Two strikes ends the sitting. It counts as an attempt, and the usual seven-day wait applies before you can try again.

  • {{ index .Data "foundationsThreshold" }}% and up
