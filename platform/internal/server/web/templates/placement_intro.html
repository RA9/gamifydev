The standard

  • {{ index .Data "minutes" }} minutes, measured by the server from the moment you begin.
  • Multiple-choice questions across five core CS topics plus Web and Backend routing topics.
  • {{ index .Data "passThreshold" }}% core passes into Computer Science Foundations.
  • {{ index .Data "foundationsThreshold" }}% core opens a generated specialization path.
  • Questions are sampled from the bank, so each sitting is different.

What the result controls

  • Below {{ index .Data "passThreshold" }}%, you receive readiness feedback and may try again after seven days.
  • From {{ index .Data "passThreshold" }}–{{ sub (index .Data "foundationsThreshold") 1 }}%, you earn a place in Computer Science Foundations.
  • At {{ index .Data "foundationsThreshold" }}% or higher, your scores generate a Frontend, Backend, or Full-Stack path.
  • A passing result is required to create a learner account.

You may browse the curriculum and practise problems without an account. Enrollment, progress tracking, and cohort work begin only after you pass.
